把 DeepSeek Harness 装进一个文件夹

解压即用，无需安装。双击一个 exe 打开独立应用窗口，自动保持最新，数据全部留在你的电脑上。

它是什么

DeepSeek Harness 的浏览器界面，配一个便携启动器，打包成一个文件夹。

绿色便携

整个文件夹拷到 U 盘或任意目录即可运行，不写注册表、不占系统目录。

独立应用窗口

用 Edge/Chrome 应用模式打开，无标签页、无地址栏，不占用浏览器。

自动升级

每次启动自动对比最新版本，先升级再启动，无需手动维护。

托盘常驻（可选）

setup.cmd 一键启用托盘：后台运行、右键菜单管理，可设开机自启。

Codex 会话同步

可选插件把本机 Codex 对话导入 Harness，自动探测位置、按目录归组。

数据本地化

会话记录、配置、凭据都在 runtime\dsh-home，整个目录即备份，卸载即删文件夹，不留残留。

快速开始

三步就能用起来。

解压

把整个 dsh-portable-win64 文件夹解压到任意位置（U 盘也可以）。

运行

双击 dsh-web.exe。首次运行需要联网初始化（约几分钟），随后自动打开独立应用窗口。Windows 若提示 SmartScreen，点“仍要运行”。

配置模型

在界面“设置”里填入你的模型 API Key，选择模型（如 deepseek-v4-pro），开始使用。

可选功能（setup.cmd）

双击 setup.cmd 打开安装菜单，按需选择：

选项作用
1创建桌面快捷方式，双击即启动
2开机自启（托盘常驻，登录后自动后台运行）
3取消开机自启
4立即启动托盘（任务栏蓝色 D 图标，右键菜单管理）
5停止所有 DSH 服务
6安装 Codex 同步插件（先运行过一次 dsh-web.exe 再装）

Codex 会话同步插件

把本机 Codex 的对话历史导入 Harness，自动探测 Codex 位置、按目录归类。

插件自动查找 Codex（配置项 codexHome → CODEX_HOME → ~/.codex），用户不需要知道 Codex 装在哪。
命令说明
/codex-sync查看状态（Codex 目录、Harness 目录）
/codex-sync detect重新探测 Codex 位置
/codex-sync list列出最近的 Codex 会话
/codex-sync sync同步最近 10 个（默认，增量）
/codex-sync sync all全量同步
/codex-sync sync recent:50同步最近 50 个
/codex-sync sync <ID 或关键字>同步指定会话

安装插件后重启 Harness；以后每次启动会自动同步最近 10 个新会话（草稿会话自动跳过）。

数据与备份

所有数据都在本文件夹内，没有隐藏的系统目录。

路径内容
runtime\dsh-home\sessions全部聊天记录（按工作区分目录）
runtime\dsh-home\.credentials.yaml模型 API 凭据
runtime\dsh-home\settings.yaml界面与模型设置
runtime\dsh-home\profiles插件与 profile 配置
runtime\dsh-home\storages工作区与会话索引
备份 = 复制整个文件夹；迁移 = 整个文件夹拷到新位置，首次运行自动重建内部链接，聊天记录不丢失。

常见问题

Windows 提示“已保护你的电脑”（SmartScreen）？
exe 未做代码签名。点“更多信息 → 仍要运行”即可。这是绿色版工具的常见现象，不表示文件有问题。
首次运行需要联网吗？
需要。首次启动会初始化 profile 并检查最新版本；之后启动只在有新版时下载更新，断网也能用现有版本。
关掉应用窗口后服务会停吗？
应用窗口模式下，关闭窗口会自动停止服务；托盘模式下，服务由托盘托管，关闭窗口不会停服务，需在托盘菜单里停止。
端口 3080 被占用或访问报 503？
默认端口 3080。如果本机代理（如 127.0.0.1:10808 这类）拦截了 localhost 请求，浏览器可能看到 503，但服务本身正常。可在 launcher.json 里改端口，或用 --port 参数。
历史加载失败 / 左侧出现“未分组”？
旧版本导入的会话可能缺字段，导致校验失败。用 node fix-scripts\repair-sessions.cjs 修复；工作区归位用 fix-scripts\fix-workspaces.cjs（均在源码包的 fix-scripts 目录）。
Mac 上能用吗？
当前 exe 是 Windows 版。Mac 上装好 Node.js，运行 launcher\build.sh 构建 mac 可执行文件，目录结构与配置完全一致；聊天记录文件可跨平台直接拷贝。
如何升级？
启动器每次启动自动检查 @deepseek-ai/dsh 最新版并升级。想手动确认：npm view @deepseek-ai/dsh version。
从哪里重新打包发布？
源码在 launcher\（启动器）与 plugins\dsh-codex-sync\（插件）。改完运行 launcher\build.ps1 重建 exe，再运行 pack.ps1 生成干净的 zip。
